06 / THREE-VALUED LOGIC SQL 语义正确性底线

三值逻辑深坑：为什么 NOT IN 遇到一个 NULL 就全盘皆空？

PostgreSQL 优化器拒绝轻易把 NOT IN 改写成 Anti Join，是因为按 SQL 标准，x NOT IN (1, 2, NULL) 展开后包含 x <> NULL，结果恒为 UNKNOWN，导致 WHERE 过滤掉所有行！
