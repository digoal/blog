03.4 · TRANSACTION MODEL · NON-AUTOCOMMIT DEFAULT

核心原理四：默认不是 autocommit，忘提交即锁等待

ECPG 默认仅在显式 EXEC SQL COMMIT 时提交；execute.c 会在空闲连接上自动发 begin transaction，极易埋下长事务隐患。

核心原理五：sqlca 是状态载体，WHENEVER 是预处理指令
