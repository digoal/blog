## 背景


[《爆炸新闻: Anthropic 推出 ant, Claude 往 CS 架构演进》](../202607/20260724_09.md)  昨天这篇分析可能过于激进了, 今天重新分析一下.  

Anthropic 出了个叫 ant 的东西，配合托管智能体架构，以后 Claude 会永远挂在线上，谁手里有 API 权限，谁就等于攥着一个数字员工的遥控器，随时可以支使它干活。听起来确实性感 —— 一个不知疲倦、随叫随到、还能被塞进任何软件里的打工人。

ant 是 Anthropic 官方出的一个命令行工具，本质是把以前你得手写一堆 curl 加 JSON 才能调用的 Claude API，封装成几行简洁的命令。

真正的重头戏其实不是 ant，而是跟它一起发布的 **Claude Managed Agents** —— 这是一整套由 Anthropic 托管的沙箱运行环境，支持长时间、有状态的会话，agent 可以在里面自主执行好几步操作，还能断点续跑。

它的调用逻辑：先定义一个 agent（它是谁），再开一个 environment（它在哪跑），然后启动一个 session，之后你就靠发"事件"跟这个跑在云端的 agent 通信。

这确实是一套标标准准的客户端-服务端结构：客户端可以是 ant，可以是 Claude Code，理论上也可以是任何写过 API 集成的第三方软件；服务端就是那个持久运行、保有状态的 session 容器。

所有软件都可以通过 API 调用 Claude 其实早就成立了 —— Claude API 本来就是开放的，不是这次才打开的新闻。真正变化的是颗粒度：以前调用 API 只能拿到"问一句答一句"的能力，现在 Managed Agents 把"能自主跑多步、能保持状态、能断点续跑"这些原本极其麻烦的工程活儿，从开发者手里接管了过来。换句话说，把一个能持续干活的智能体嵌进自己产品里的门槛，被显著拉低了。 

Managed Agents 计费方式：token 费用不变，另外单独收一笔叫 session runtime 的钱，每小时 0.08 美元，精确到毫秒计费，而且只有 session 处于"正在执行"状态才计费 —— 等待用户输入、等待工具确认、排队、终止，这些状态统统免费。

如果你的 agent 陷入无意义的空转循环，你其实是在为整段时间的云端基础设施买单；一个真的 24 小时不间断运行的 agent，理论上每月光运行时费用封顶 57.6 美元左右。这个数字对个人来说也不小, 其实只要 Agent 记忆和 session ID 可被保留, 并不需要实际意义上的资源永远在线, 除非你的会话非常繁忙, 否则 serverless 的架构更好.

这套"Claude 底层能力被 API 化之后到底谁能吃到最大一块蛋糕"? 

历史上其实反复上演过。Stripe 把支付能力封装成几行代码接进去，结果不是所有公司都变成了 Stripe 的员工，而是催生出一大批基于 Stripe 的垂直 SaaS；AWS Lambda 把"计算"变成按次付费的能力，结果也不是"AWS 接管了所有公司的运维"，而是催生了大量事件驱动型应用。真正决定价值分配的从来不是"能不能调用"这个开关，而是底层平台方到底把多少原本属于应用层的复杂度也一并接管了过去。Managed Agents 目前确实在往这个方向走 —— 多智能体协作、agent 自我评估这些原本要靠应用层自己搭的能力，正在逐步被纳入托管范围。但眼下这些还停留在"研究预览、需要单独申请权限"的早期阶段，开发者社区里已经有人在盘算要不要自建开源替代方案来对冲被单一平台绑定的风险。 

但是, 不管怎么说, Claude 在 AI 产业链的必经环节上, 这事的目的就是把 Claude 粘性、用户数做大, 收更多的“过路费”. 

再看人与 AI 协作架构，人类介入的时间点其实只有两处：设定任务边界（agent 的权限范围、environment 的能力边界）的那一刻，和事后审阅结果的那一刻。中间那段自主执行的过程，是 agent 自己跑完的。这更像是把工作范围交代清楚之后放手让一个新员工去干、定期看汇报。 这就引入了另一个问题, AI 与人协作的问题, 可参考阅读:  
- [《德说-第524期, 混沌大学的地基松动了, 我们与 AI 到底如何共处?》](../202607/20260721_01.md)  
- [《德说-第518期, 为什么用了 AI 我却越来越累了? 思维要从员工转变成管理者, 还要定义路由和交付契约》](../202607/20260715_03.md)  
- [《PMP 思维筑基课: 项目管理（PMP）底层公理与定律体系 —— 面向 Agent 编排与协作》](../202607/20260724_01.md)  

"Claude Managed Agents" 这个产品未来会怎么演进? 可以盯着有没有主流的、跟 Anthropic 没有直接关系的第三方软件，真的把这套托管智能体架构当成自己产品里"AI 员工"功能的底层，而且这类案例在半年内明显增多 —— 如果看到了，说明这套生态是真的被打开了，而不是还停留在开发者论坛里的技术畅想。
