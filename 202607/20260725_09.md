## 背景

今天全是实操 —— 从安装开始，一步步带你跑通 PowerMem 的核心功能，最后再跟 Mem0 和 Cognee 做一波真实对比。

## 先别急着装，搞清楚场景

在敲命令之前，先问自己一个问题： **我到底需不需要一个专门的「记忆」项目？**

如果你是下面几种情况，PowerMem 很适合你：

- 你在做一个 AI 客服，希望它记得每个用户的偏好和历史
- 你在搞多 Agent 系统，AgentA 知道的事 AgentB 也得知道
- 你希望 Agent 用久了能「进化」 —— 从经验中学习，而不是每次都从零开始
- 你受够了每次对话都塞一堆历史记录进 Context Window

如果只是给 ChatGPT 套个壳，那 PowerMem 对你来说太重了。但如果上面任意一条击中了你，继续往下看。

---

## 第一步：安装

```bash
# 推荐：常用本地完整安装
pip install "powermem[cli,server,seekdb]"
```

这个命令装了三样东西：
- `cli`：pmem 命令行工具
- `server`：HTTP API 服务 + MCP 支持
- `seekdb`：嵌入式数据库，零配置就能跑

没有 `seekdb` 的话，你需要自己配 OceanBase 或 PostgreSQL。对于尝鲜来说，seekdb 是最快路径。

验证安装：

```bash
pmem --version
```

如果看到版本号，恭喜，装好了。

---

## 第二步：配置

PowerMem 只需要一个 LLM 的 API key 就能跑。复制示例配置文件：

```bash
cp .env.example .env
```

打开 `.env`，找到你的 LLM 提供商那一行。我用的是通义千问（因为 PowerMem 是 OceanBase 出品，对阿里系支持最好）：

```bash
# 只用配这一个就能跑
DASHSCOPE_API_KEY=sk-你的key
```

默认的 Embedding 模型是本地的 `all-MiniLM-L6-v2`（384 维），不需要 API key，第一次用会自动下载。也就是说 —— **配一个 key 就够了**。

---

## 第三步：跑起来看看

创建一个 Python 文件 `demo.py`：

```python
from powermem import Memory, auto_config

# 自动从 .env 加载配置
memory = Memory(config=auto_config())

# 添加几条记忆
memory.add("用户喜欢 Python 编程，特别是数据科学方向", user_id="user001")
memory.add("用户在一家金融科技公司做后端开发", user_id="user001")
memory.add("用户偏好深色模式的 IDE", user_id="user001")

# 搜索记忆（语义搜索，不是关键词匹配）
results = memory.search("用户的编程偏好", user_id="user001")
print("搜索结果：")
for r in results.get("results", []):
    print(f"  - {r['memory']}")
```

执行：

```bash
python demo.py
```

你会看到类似这样的输出：

```
搜索结果：
  - 用户喜欢 Python 编程，特别是数据科学方向
  - 用户在一家金融科技公司做后端开发
```

注意一个细节：我搜的是「编程偏好」，它不光返回了第一条，还返回了「金融科技公司做后端」 —— 因为语义上后端开发和编程偏好是相关的。这就是语义搜索和关键词搜索的区别。

## 第四步：智能记忆 —— 让 LLM 帮你提取事实

上面用的是原始文本存储。PowerMem 更强大的用法是让 LLM 自动从对话中抽取事实：

```python
from powermem import Memory, auto_config

memory = Memory(config=auto_config())

# 传入对话，让 LLM 自动提取关键信息
result = memory.add(
    messages=[
        {"role": "user", "content": "你好，我叫张三，在蚂蚁集团做算法工程师"},
        {"role": "assistant", "content": "你好张三！算法工程师，听起来很酷"},
        {"role": "user", "content": "我主要负责推荐系统，平时用 Python 和 TensorFlow"}
    ],
    user_id="user002",
    infer=True  # 开启智能抽取
)

print("抽取到的事实：")
for r in result.get("results", []):
    print(f"  [{r.get('event', 'N/A')}] {r.get('memory', '')}")
```

执行后你会看到类似：

```
抽取到的事实：
  [ADD] 姓名是张三
  [ADD] 在蚂蚁集团做算法工程师
  [ADD] 负责推荐系统
  [ADD] 使用 Python 和 TensorFlow
```

看到没？LLM 自动把一段对话里的关键信息提取成了结构化的事实。而且如果你再告诉它「我最近转到飞书团队做前端了」，它不会简单追加一条，而是会把旧信息标记为 UPDATE，自动更新。

智能模式支持六种操作：

| Event | 含义 | 举例 |
|-------|------|------|
| ADD | 新增事实 | 第一次知道用户名字 |
| UPDATE | 更新已有事实 | 用户换工作了 |
| DELETE | 删除矛盾事实 | 用户说「我不喝咖啡了」→ 删除「喜欢咖啡」 |
| NONE | 检测到重复 | 又说了一遍同样的话 |
| MERGE | 合并相似记忆 | 把两条关于编程语言的信息合并 |
| REWRITE | 重写优化 | 用更精确的语言重写一条模糊记忆 |

这是 PowerMem 和普通向量数据库的核心区别之一 —— **它理解语义，不只是算相似度**。

## 第五步：玩点高级的 —— Experience + Skill 蒸馏

这是 PowerMem 1.2.0 的招牌功能，也是它自称为「自进化记忆」的原因。

场景：你做了一个 AI 客服 Agent，它在跟用户交互中积累了经验。你希望它能从经验中学习，下次遇到类似问题能直接给出最佳方案。

先添加一条经验：

```python
from powermem import Memory, auto_config

memory = Memory(config=auto_config())

# 添加经验：Agent 做了什么，效果如何
memory.add_experience(
    action="推荐了 OAuth2 + JWT 方案",
    outcome="用户接受了，并且反馈方案很清晰",
    context="用户询问 API 网关安全配置方案",
    user_id="agent_learn"
)

memory.add_experience(
    action="推荐了 API Key 方案",
    outcome="用户质疑安全性，最终改用了 OAuth2",
    context="用户询问 API 网关鉴权方式",
    user_id="agent_learn"
)

# 一键蒸馏：从经验中提炼出可复用的技能
memory.distill_all(user_id="agent_learn")

# 搜索技能
skills = memory.search_skills("API 安全方案", user_id="agent_learn")
print("提炼出的技能：")
for s in skills.get("results", []):
    print(f"  - {s.get('memory', '')}")
```

蒸馏之后，如果用户再次问 API 安全相关的问题，Agent 不再需要从头推理，而是直接调用这条技能。这就是「经验 → 技能」的进化闭环。

官方数据：在 AppWorld 基准测试上，使用蒸馏后通过率从 24% 提升到 39%，提升了 62.5%。

## 第六步：用命令行日常操作

如果你不想写 Python，PowerMem 提供了 `pmem` 命令行：

```bash
# 添加记忆
pmem memory add "用户喜欢深色模式" --user-id user001

# 搜索记忆
pmem memory search "主题偏好" --user-id user001

# 查看所有记忆
pmem memory list --user-id user001

# 交互式 REPL
pmem shell

# 查看统计
pmem memory stats --user-id user001
```

CLI 模式特别适合在脚本里用，或者快速调试。

## 跟 Mem0 和 Cognee 的真实对比

我在三台同样的机器上做了相同的测试，以下是真实的体感对比：

### 场景一：记录用户偏好

| 操作 | PowerMem | Mem0 | Cognee |
|------|----------|------|--------|
| 安装到可用 | ~30秒（含 seekdb 下载） | ~20秒 | ~40秒（需装 Ladybug） |
| 添加记忆 | `memory.add(text)` | `memory.add(text)` | `cognee.add(text)` |
| 搜索记忆 | `memory.search(query)` | `memory.search(query)` | `cognee.search(query)` |
| 智能提取 | ✅ infer=True 自动抽取 | ✅ 默认就提取 | ❌ 无此功能 |
| 重复检测 | ✅ NONE 事件去重 | ❌ 会重复添加 | ❌ 按文档块去重 |
| 冲突处理 | ✅ DELETE + 自动更新 | ❌ 只加不减 | ❌ 不适用 |

### 场景二：构建知识图谱

| 操作 | PowerMem | Cognee |
|------|----------|--------|
| 图存储 | ✅ OceanBase 图存储 | ✅ NetworkX + Ladybug |
| 图搜索 | ✅ 混合检索含图信号 | ✅ 14种搜索策略 |
| 查询三元组 | ⚠️ 内置但不暴露 | ✅ TRIPLET_COMPLETION |
| 多跳推理 | ✅ 3跳图遍历 | ✅ GRAPH_COMPLETION |

### 场景三：多 Agent 场景

| 操作 | PowerMem | Mem0 | Cognee |
|------|----------|------|--------|
| 多用户隔离 | ✅ 原生 | ✅ 原生 | ❌ 无概念 |
| 多 Agent 隔离 | ✅ 原生 | ❌ 无 | ❌ 无 |
| 记忆共享 | ✅ Group 机制 | ❌ | ❌ |
| 权限控制 | ✅ 读/写/管理 | ❌ | ❌ |

### 一句话选型

- **PowerMem**：Agent 记忆生命周期管理，需要自进化、多智能体、遗忘曲线的场景
- **Mem0**：只想简单记录用户对话上下文，追求极简 API
- **Cognee**：需要从文档构建知识图谱，做企业知识库、RAG 增强

## 避坑指南

实操过程中遇到的几个坑，帮你跳过：

### 1. `.env` 文件必须在当前目录

`auto_config()` 只在**当前工作目录**查找 `.env`。如果你在别的目录运行脚本，记得 `export` 环境变量或用绝对路径。

### 2. seekdb 只在第一次安装时下载

第一次 import powermem 时会自动下载模型和初始化 seekdb，大概需要十几秒。之后就不需要了。

### 3. `infer=True` 需要 LLM

智能抽取和去重依赖 LLM 调用。如果你传 `infer=False`，就是纯粹的向量存储，不会触发 LLM。

### 4. 中文搜索建议用中文 Embedding

默认的 `all-MiniLM-L6-v2` 对中文效果一般。生产环境建议换成 Qwen 的 `text-embedding-v4` 或 `text-embedding-v3`，对中文支持好很多。

---

## 总结

PowerMem 的核心优势不是某一个功能，而是**完整的记忆生命周期管理**：

- **存**：向量 + 全文 + 图，三重索引
- **管**：LLM 智能抽取、去重、更新、合并
- **用**：语义搜索 + 时间衰减排序
- **进化**：Experience → Skill 双层蒸馏
- **扩展**：多 Agent、多用户、全平台集成

如果说 Mem0 是个记事本，Cognee 是个图书馆，那 PowerMem 就是一个**大脑** —— 它会记住、会忘记、会学习、会进化。
