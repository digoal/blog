digoal

## 背景 
  
最近 IvorySQL 发起了一项 “寻找开源贡献者！IvorySQL 10个新手友好任务等你来认领” 的活动  
  
https://mp.weixin.qq.com/s/qKdoG4okYr1lA0iXkpls0g  
  
其实你只要有工具的话, 这个活非常好接, 我下面演示一下如何使用我的“屠龙刀”接这个私活. [《德说-第531期, 我的 AI “屠龙刀”来了》](../202608/20260801_01.md)  
  
1、把 IvorySQL fork 到自己名下  
  
https://github.com/digoal/IvorySQL  
  
2、clone 到本地  
```  
git clone --depth 1 git@github.com:digoal/IvorySQL.git  
```  
  
3、创建一个新的 branch , 例如与你要实现的 issue NO 同名.  
  
https://github.com/IvorySQL/IvorySQL/issues/1482  
  
```  
cd IvorySQL  
  
git log  
  
commit efd98db2a8c6fc8b85d168b539e4c0089e44df7c (grafted, origin/master, origin/HEAD, master)  
Author: gaoxueyu <44825804+gaoxueyu@users.noreply.github.com>  
Date:   Fri Jul 31 13:59:22 2026 +0800  
  
    Merge pull request #1473 from bigplaice/ai-assistant  
  
    add more contents into coding-assistants doc  
  
git checkout -b 1482 efd98db2a8c6fc8b85d168b539e4c0089e44df7c  
```  
  
4、修改 `.gitignore`, 加一行, 忽略 codegraph 目录.  
```  
# add by ai  
.codegraph/  
```  
  
5、假设你已经安装了 codegraph , 没安装的话参考我写的 handbook: https://github.com/digoal/codegraph-handbook/blob/main/chapters/02-quickstart.md  
```  
cd IvorySQL  
codegraph init  
```  
  
这一步是建立代码地图, 这个文件可以用 sqlite 直接打开.  
```  
$ cd .codegraph  
  239M  8  1 19:40 codegraph.db  
  
$ sqlite3 ./codegraph.db  
SQLite version 3.43.2 2023-10-10 13:08:14  
Enter ".help" for usage hints.  
sqlite> .tables  
edges               nodes               nodes_fts_data      project_metadata  
files               nodes_fts           nodes_fts_docsize   schema_versions  
name_segment_vocab  nodes_fts_config    nodes_fts_idx       unresolved_refs  
```  
  
6、用 Claude 拿下私活  
  
```  
cd IvorySQL  
  
claude  
  
# 输入提示  
  
优先使用 codegraph mcp tool 进行代码搜索. 实现这个 issue:  
拷贝 1482 issue 的内容  
```  
  
7、完成后, 继续让 claude 生成提交信息  
  
8、提交到自己的仓库  
```  
cd IvorySQL  
git add .  
git commit -m 'Reference issue no #1482  , 并将 commit message 拷贝到这里'  
git push origin 1482  
```  
  
9、提交 PR  
  
打开 https://github.com/digoal/IvorySQL 并提交 PR, 本地选 1482 分支, 远程选 master 分支.  
  
如下  
  
https://github.com/IvorySQL/IvorySQL/pull/1490  
  
以上就是一次"Claude + Codegraph 接 IvorySQL 开发私活"实录, 仅供参考.
