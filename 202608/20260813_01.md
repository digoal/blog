## 背景  
  
弄好[《我的“屠龙刀” | “AI Agent + 数据库 + Skills + 记忆层” Docker 镜像及制作过程》](../202607/20260730_02.md)   后, 开始使用起来了.  
  
于是发现了第一个需求, 我的一个容器中的 Hermes 能不能服务于多个 微信号 呢?  
  
我家里人每个人都需要一个自己的 Claw , 说干就干, 原来 Hermes 通过 profile 就能支持.  
  
只是默认就有一个, 我们不知道而已.  
  
  
```  
# 查看 profile 帮助  
hermes profile --help  
  
# 列出当前有哪些 profile  
hermes profile list  
  
# 创建一个名为 digoal 的 profile  
hermes profile create digoal  
  
# 诊断名为 digoal 的 profile  
hermes --profile digoal doctor  
  
# 自动修复名为 digoal 的 profile  
hermes --profile digoal doctor --fix  
  
# 配置名为 digoal 的 profile  
hermes --profile digoal setup  
  
# 在 setup 中选择 full 设置, 可配置网关
  
# 启动名为 digoal 的 profile 的网关  
hermes --profile digoal gateway --accept-hooks restart
  
# 用配置好的网关客户端, 例如微信、飞书等, 发送消息会收到类似这样的信息
Hi~ I don't recognize you yet!

Here's your pairing code: xxxxxx

Ask the bot owner to run:
hermes pairing approve feishu xxxxxx

# 在容器中另外开一个窗口, 执行即可, 记得带上 profile 
hermes --profile digoal pairing approve feishu xxxxxx
```  
  
如果都是自己用的话, 建议所有 agent 共享一份 skills, 可以软链接共享. hermes 不同的 profile skills 都是在自己 profile 目录中, 所以可以在创建好 profile 后, 做一下软链.  
  
  
例如  
```  
# hermes profile list  
  
 Profile          Model                        Gateway      Alias        Distribution  
 ───────────────    ───────────────────────────    ───────────    ───────────    ────────────────────  
 ◆default         MiniMax-M2.7                 running      —            —  
    digoal        MiniMax-M2.7                 running      digoal     —  
```  
  
profile 配置文件在哪?  
```  
~/.hermes/profiles  
  
这个目录中就有创建好的 profile:  
digoal  
```
