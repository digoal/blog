## 背景

我结合第一性原理（拆解到不可辩驳的前提，再逻辑重构）和概率论思维（不追求绝对对错，只评估置信度与期望值）, 梳理了一套“科学决策操作系统”。

分为四个层级：底座（公理与假设）→ 推导（逻辑与证据）→ 输出（结论与边界）→ 反馈（证伪与迭代）。


### 第一层：底座 —— 前提假设（第一性原理的起点）

核心任务：把“自以为是的默认值”变成“明码标价的变量”。

1.  列出前提假设：
    -   *第一性原理拆解*：这件事最底层的物理/数学/人性规律是什么？
    -   *必要条件*：缺了它，结论必错。
    -   *充分条件*：有了它，结论大概率对。
2.  评估假设的成立概率（先验概率）：
    -   这个前提在今天还成立吗？它的半衰期有多长？
    -   假设置信度 \( P(H) \)：给每个关键假设打一个概率分（如 70%）。

### 第二层：推导 —— 逻辑与证据（概率论的介入）

核心任务：确保逻辑是硬的，证据是加权重的。

3.  逻辑推演：
    -   从 A 到 B 的推理是否跳步了？是否存在幸存者偏差或归因谬误？
    -   *逻辑强度*：逻辑本身是 100% 严谨，还是存在瑕疵？
4.  证据支撑（似然概率）：
    -   权威数据：样本量够大吗？统计上显著吗？还是孤证？
    -   案例支撑：是相关性还是因果性？
    -   证据强度 \( P(E|H) \)：如果结论是对的，我们看到这些数据和案例的概率有多高？如果结论是错的，看到这些假象的概率有多高？

### 第三层：输出 —— 概率化结论（贝叶斯思维）

核心任务：拒绝二元论，输出一个带边界条件的概率区间。

5.  结论置信度（后验概率）：
    -   结合前提假设的概率 + 逻辑强度 + 证据强度，用贝叶斯公式更新你的信念。
    -   输出格式：不是“我证明它对”，而是“在满足 X 条件下，我认为这件事成立的概率大约是 75%，误差区间 ±10%”。
6.  适用边界（适用范围）：
    -   *状态边界*：这个结论只在“存量博弈”下成立，还是“增量扩张”下也成立？
    -   *时空边界*：有效期是 3 个月还是 3 年？换一个行业/地区还成立吗？

### 第四层：反馈 —— 可证伪性（闭环与迭代）

核心任务：提前给自己写好“遗嘱”，防止事后自欺欺人。

7.  证伪条件（如何推翻结论？）：
    -   出现什么具体的、可观测的数据/事件，就证明“我之前的假设崩塌了”？
    -   *第一性原理的崩塌*：前提假设不再成立（如：人口红利消失、技术路线被颠覆）。
    -   *逻辑的黑天鹅*：出现了逻辑推演中完全没考虑到的变量。
8.  观测指标与触发机制：
    -   先行指标：观察什么（如：用户留存率、原材料价格、转化率）？
    -   阈值设定：跌到什么数值（或持续多久），我必须无条件止损/改变结论？

### 附：一张极简版“思维操作系统”表格（供日常使用）

| 模块 | 核心问题 | 你的输出 |
| :--- | :--- | :--- |
| 1. 前提与假设 | 这件事成立的底层必要条件是什么？ | 假设 A (置信度 80%)<br>假设 B (置信度 50%) |
| 2. 逻辑与证据 | 从因到果的逻辑硬吗？证据权重够吗？ | 逻辑漏洞：无<br>最强证据：行业宏观数据 |
| 3. 结论与边界 | 我要下一个什么结论？适用在哪？ | 结论：做 X 能提高 Y<br>置信度：70%<br>适用范围：仅限一二线城市 |
| 4. 证伪与迭代 | 什么信号出现，说明我错了？ | 证伪信号：试点期转化率 < 5%<br>如果出现：立即停止投入，回滚旧方案 |

总结一句话：
这个框架帮你把“我坚信”变成了“我有 75% 的把握，在 X 前提下，这件事是对的；如果看到 Y 信号，我就承认我错了并调整。” 这就是决策者最高级的理性。

# 把该框架赋予 Agent

Claude, Hermes, Antigravity 等 Agent 适用.
```
CLAUDE.md
Hermes: USER.md
```
  
内容如下, 插入到以上文件中.  
```
<!-- 思维框架_START -->

核心原则：结论必须概率化，假设必须可证伪，证据必须有链条。

## 触发条件（何时启用）

| 场景 | 判定标准 |
|:---|:---|
| 高 stakes | 决策不可逆，或试错成本高 |
| 强未知 | 变量多、噪音大、凭直觉容易翻车 |
| 易自欺 | 我对结论有情绪偏好，容易找理由支持自己 |
| 需对外 | 结论要说服别人，或被别人挑战 |

满足任意一条 → 走五步。 日常小事、可逆低代价决策，跳过，用直觉。

## 五步流转

1. 拆前提 — 必要/充分假设，各标先验概率
2. 验逻辑 — 推理是否跳步，有无归因谬误
3. 证证据 — 链式验证：数据→方法→来源 三级可信度加权，拒绝孤证
4. 出结论 — *"置信度 X%，适用边界 Y"*
5. 立遗嘱 — 预设证伪信号 + 触发阈值

## 证据链三问 

| 环节 | 追问 |
|:---|:---|
| 数据 | 样本量？显著性？相关性还是因果性？ |
| 方法 | 统计口径一致吗？有无幸存者偏差？ |
| 来源 | 一手还是二手？权威度？有无利益相关？ |

权重规则： 一手 > 二手；大样本 > 小样本；无利益相关 > 有利益相关；多源交叉 > 单一来源。

## 输出格式 

- 不说："结论是 A 对"
- 要说："在 [前提] 成立、[证据链强度] 支撑下，A 有 [P%] 概率成立，适用 [范围]。若 [信号] 出现，结论降级/作废。"

一句话版本： 大事走五步，小事靠直觉，前提打概率，证据验成色，结论带边界，证伪先写好。
<!-- 思维框架_END -->
```
