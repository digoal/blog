## 一、制作 Debian USB 安装盘  
  
### 在 macOS 上制作  
  
#### 1. 下载 Debian ISO  
从 [Debian 官网](https://www.debian.org/distrib/) 下载 ISO 文件（推荐 `amd64` 架构的 `netinst` 网络安装版）。  
  
#### 2. 确认 U 盘设备标识符  
```bash  
# 插 U 盘前  
diskutil list  
  
# 插 U 盘后再次执行，对比找出新增的设备  
diskutil list  
# 记下标识符，如 disk2 或 disk6  
```  
  
#### 3. 卸载 U 盘  
```bash  
sudo diskutil unmountDisk /dev/diskX   # 将 diskX 替换为实际标识符  
```  
  
#### 4. 写入 ISO 镜像  
```bash  
sudo dd if=/path/to/debian.iso of=/dev/rdiskX bs=1m  
```  
> 提示：可将 ISO 文件直接拖入终端自动填入路径。  
  
#### 5. 弹出 U 盘  
```bash  
sudo diskutil eject /dev/diskX  
```  
  
### 启动安装  
- 开机时连续按 **`F12`** 进入启动菜单  
- 选择 U 盘启动（通常显示为 `USB HDD`）  
- 安装时有图形界面, 不要安装第三方应用, 选择清华源, 采用单大盘根分区, (如果不打算配置 swapness, 则不要swap分区也行)

## 二、网络配置  
  
### 配置静态 IP  
  
#### 1. 查看网卡名称  
```bash  
ip link  
# 无线网卡通常为 wlan0 或 wlp5s0  
```  
  
#### 2. 编辑网络配置文件  
```bash  
sudo nano /etc/network/interfaces  
```  
  
#### 3. 配置静态 IP（示例）  
```bash  
auto wlp5s0  
iface wlp5s0 inet static  
    address 192.168.31.160  
    netmask 255.255.255.0  
    gateway 192.168.31.1  
    dns-nameservers 8.8.8.8 114.114.114.114  
    wpa-ssid Redmi_keting_5G  
    wpa-psk your_password  
```  
  
> ⚠️ **注意**：确保 `address` 不与其他设备冲突，且不在 DHCP 自动分配范围内。  
  
#### 4. 重启网络服务  
```bash  
sudo systemctl restart networking  
```  
  
#### 5. DNS 修复（如果解析 URL 失败）  
```bash  
# 临时修复  
echo "nameserver 8.8.8.8" | sudo tee /etc/resolv.conf  
echo "nameserver 114.114.114.114" | sudo tee -a /etc/resolv.conf  
  
# 永久修复  
sudo rm /etc/resolv.conf  
echo "nameserver 8.8.8.8" | sudo tee /etc/resolv.conf  
echo "nameserver 114.114.114.114" | sudo tee -a /etc/resolv.conf  
```  
  
#### 6. 验证网络  
```bash  
ip addr show wlp5s0  
ping -c 4 8.8.8.8  
```

## 三、PostgreSQL 安装  
  
参考: https://www.postgresql.org/download/linux/debian/  
  
### 修改认证方式（安全加固）  
```bash  
sudo nano /etc/postgresql/*/main/pg_hba.conf  
```  
  
将 `local all postgres peer` 改为：  
```  
local all postgres scram-sha-256  
```  
  
```bash  
sudo systemctl restart postgresql  
```

## 四、NVIDIA 显卡驱动安装  
  
### 1. 确认显卡型号  
```bash  
lspci | grep -i nvidia  
# 输出示例: NVIDIA Corporation GP108M [GeForce MX150]  
```  
  
### 2. 确保软件源包含 non-free  
```bash  
cat /etc/apt/sources.list | grep -v "^#" | grep deb  
# 确保末尾有 main contrib non-free non-free-firmware  
```  
  
### 3. 更新源并安装驱动  
```bash  
sudo apt update  
sudo apt install nvidia-detect -y  
nvidia-detect   # 查看推荐驱动  
sudo apt install nvidia-driver firmware-misc-nonfree -y  
```  
  
### 4. 重启系统  
```bash  
sudo reboot  
```  
  
### 5. 验证驱动安装  
```bash  
nvidia-smi  
```  
  
**预期输出示例**：  
```  
+-----------------------------------------------------------------------------------------+  
| NVIDIA-SMI 550.163.01             Driver Version: 550.163.01     CUDA Version: 12.4     |  
|-----------------------------------------+------------------------+----------------------+  
| GPU  Name                 Persistence-M | Bus-Id          Disp.A | Volatile Uncorr. ECC |  
|=========================================+========================+======================|  
|   0  NVIDIA GeForce MX150           On  | 00000000:01:00.0 Off |                  N/A |  
| N/A   42C    P8             N/A / ERR!  |       0MiB /   2048MiB |      0%      Default |  
+-----------------------------------------+------------------------+----------------------+  
```  
  
> ⚠️ **Secure Boot 处理**：如果驱动加载失败，检查 Secure Boot 状态：  
> ```bash  
> mokutil --sb-state  
> ```  
> 如为 `enabled`，需在 BIOS 中关闭 或 通过 MOK 界面注册密钥。

## 五、Samba 文件共享安装配置与优化  
  
### 1. 安装 Samba  
```bash  
sudo apt update  
sudo apt install samba smbclient cifs-utils -y  
```  
  
### 2. 创建共享目录  
```bash  
sudo mkdir -p /srv/samba/share  
sudo chown nobody:nogroup /srv/samba/share  
sudo chmod 0777 /srv/samba/share  
```  
  
### 3. 配置 Samba  
```bash  
sudo nano /etc/samba/smb.conf  
```  
  
在文件末尾添加：  
```ini  
[share]  
    path = /srv/samba/share  
    browseable = yes  
    read only = no  
    guest ok = no  
    create mask = 0644  
    directory mask = 0755  
    force user = your_username  
    force group = your_username  
    oplocks = yes  
    level2 oplocks = yes  
```  
  
### 4. 优化性能（在 [global] 部分添加）  
```ini  
[global]  
   server min protocol = SMB2  
   client min protocol = SMB2  
   socket options = TCP_NODELAY IPTOS_LOWDELAY SO_RCVBUF=131072 SO_SNDBUF=131072  
```  
  
### 5. 设置 Samba 用户密码  
```bash  
sudo smbpasswd -a your_username  
# 此用户必须先存在于系统中, 例如 root  
  
# 这个密码是你在 macOS 上连接时需要输入的  
```  
  
### 6. 配置防火墙  
```bash  
sudo ufw allow samba  
# 或精细开放端口  
sudo ufw allow 139/tcp  
sudo ufw allow 445/tcp  
```  
  
### 7. 重启服务  
```bash  
sudo systemctl restart smbd  
sudo systemctl enable smbd  
```  
  
### 8. macOS 连接方式  
- Finder → 前往 → 连接服务器 (`Command + K`)  
- 输入：`smb://192.168.31.160/share`  
- 用户名：your_username，密码：Samba 密码  
  
### 9. 固定到 Finder 侧边栏  
- 连接成功后，将共享盘图标**拖拽**到 Finder 侧边栏的“位置”区域

## 六、SSH 服务配置  
  
### 1. 安装 SSH 服务  
```bash  
sudo apt update  
sudo apt install openssh-server -y  
sudo systemctl start ssh  
sudo systemctl enable ssh  
```  
  
### 2. 查看 Debian IP 地址  
```bash  
ip addr show | grep inet  
```  
  
### 3. 在 macOS 上配置免密登录  
  
#### 生成新密钥（不覆盖已有密钥）  
```bash  
ssh-keygen -t ed25519 -C "debian-server" -f ~/.ssh/id_ed25519_debian  
```  
  
#### 上传公钥到 Debian  
```bash  
ssh-copy-id -i ~/.ssh/id_ed25519_debian.pub root@192.168.31.160  
```  
  
#### 配置 SSH 客户端 macOS（~/.ssh/config）  
```ssh-config  
Host debian  
    HostName 192.168.31.160  
    User root  
    IdentityFile ~/.ssh/id_ed25519_debian  
    TCPKeepAlive yes  
    ServerAliveInterval 15  
    ServerAliveCountMax 3  
```  
  
#### 测试免密登录  
```bash  
ssh debian  
```  
  
### 4. 安全加固（可选）  
```bash  
sudo nano /etc/ssh/sshd_config  
```  
  
```ini  
PermitRootLogin no  
PasswordAuthentication no  
```  
  
```bash  
sudo systemctl restart sshd  
```  
  
> ⚠️ 禁用密码登录前，务必确认密钥登录已正常工作。  
  
### 5. 解决终端字符显示问题  
  
直接 ssh 连接, 而不是在脚本中使用 spwan , expect.  
  
可用 alias haier='TERM=xterm-256color LANG=en_US.UTF-8 ssh -o SendEnv=LANG -o SendEnv=LC_ALL -o TCPKeepAlive=yes -o ServerAliveInterval=15 -o ServerAliveCountMax=3 -i ~/.ssh/id_ed25519_debian root@192.168.31.160 -p 22'  
  
#### 在 macOS 上配置 SSH 环境变量传递  
编辑 `~/.ssh/config`：  
```ssh-config  
Host debian  
    SendEnv LANG LC_ALL  
    SetEnv LANG=en_US.UTF-8 LC_ALL=en_US.UTF-8  
```  
  
#### 在 Debian 上生成并配置 locale  
```bash  
sudo apt install locales -y  
sudo locale-gen en_US.UTF-8  
sudo update-locale LANG=en_US.UTF-8 LC_ALL=en_US.UTF-8  
```  
  
#### 验证  
```bash  
echo -e "\xF0\x9F\x98\x80"  
# 应显示 😀  
```

|------|------|
